# 拾荒机 · Automatic Collector

> 本项目由 AI（Codex）生成，包括代码、美术资源和动画。

饥荒联机版（DST）自动采集模组。木制小车逐个拾取、采摘和收获，并送至附近箱子。

当前版本 **0.4.1**

## 制作与操作

- 在炼金引擎旁解锁：**木板 × 2、石砖 × 2、齿轮 × 1**。在科学或建筑筛选中查找“拾荒机”。
- 从背包放到地上，放置位置就是工作中心；默认工作半径约 3 块地皮。
- 在范围内放置接收箱子。**默认只送到已有同类物品的箱子，请先放入样品**；可修改“运输规则”以使用空箱子。
- **右键**暂停或启动；**左键**捡起后重新放置，可移动工作中心。
- 捡起小车时，携带的货物会交还拾取者；背包放不下的物品会掉在地上。

## 采集与运输

- 拾取普通掉落物，采摘成熟的草、树枝、浆果等资源，收获成熟作物。
- 巨大作物会先采收，再用冲撞打开，分别拾取蔬菜和种子；打蜡的巨大作物会保留。
- 每次只处理一个目标。同类物品可以合并时，先凑满一组再运输；没有更多合适目标时，未满组也会送走。
- 当前默认携带一组物品。蔬菜、种子等不同产物分组运输，额外产物先留在地上；不会强行合并不同物品或皮肤。
- 下一株的产量放不下时会先卸货。箱子满了、被其他人打开或不接收货物时，会尝试其他可用箱子；没有合适箱子时保留货物并等待。
- 不提供储物界面，不消耗燃料，不参加战斗，也不会砍树、挖植株、浇水、照料、播种或敲建筑。
- 不收集活物、陷阱诱饵、背包、容器及普通重物等。玩家远离导致小车休眠时停止工作；船上只处理同一艘船的物品。

## 配置

在世界的服务器模组配置中调整：

| 配置 | 默认 | 可选值 |
| --- | --- | --- |
| 工作半径 | 12，约 3 块地皮 | 8 / 12 / 16 |
| 运输规则 | 仅已有同类物品的箱子 | 仅同类箱子 / 优先同类，也用空箱 |
| 自动采摘与收获 | 开启 | 开启 / 关闭 |
| 敲开巨大作物 | 开启 | 开启 / 关闭 |

## 常见问题

**小车没有开始工作**：检查是否暂停、目标是否成熟、箱子是否在范围内且有足够容量。默认运输规则要求箱子中已有同类样品；关闭箱子界面后再观察。

**与其他模组一起使用**：使用常规物品、采摘和容器规则的模组通常可以兼容。特殊角色限制、自定义采摘或箱子规则需要实际测试；未知产物可能被跳过或等待合适箱子。

**升级功能**：当前没有升级物品或升级配方。
