# 文档索引

按读者选择入口。根目录 README 随模组发行；本目录的玩家验收、开发者与 AI 文档只保留在源码仓库。

| 读者 | 入口 | 阅读目标 |
| --- | --- | --- |
| 玩家 | [玩家说明](../README.md)、[玩家文档](user/README.md) | 制作和使用小车、调整配置、排查问题、参与实机验收 |
| 开发者 | [开发者文档](developer/README.md) | 理解实现、接入扩展、构建资源、运行测试和生成发行目录 |
| AI | [AGENTS.md](../AGENTS.md)、[AI 文档](ai/README.md) | 遵守协作及写作规则，查找生成提示词和历史任务上下文 |

## 维护位置

- 面向玩家的当前行为写入根目录 README；需要参与实机测试的详细清单写入 `user/TESTING.md`。
- 可重复的开发步骤、当前架构、接口和资源规格写入 `developer/`。
- AI 工作约束和写作规则写入 `ai/`；图片生成提示词与参考图写入 `ai/art/`。
- 带有日期、基线版本和任务上下文的执行结果、阶段计划与交接记录写入 `ai/history/`。

同一事实只在对应主文档维护，其他文档使用链接引用。历史记录中的成功数量、分支、旧计划和“本轮”状态只适用于对应任务，不能直接作为当前实现或当前验证结果。
