# 小车音效

适用版本：0.7.3。普通版仍叫「拾荒机」，升级版改为「采集车」。两款车使用独立的原创音效；升级配方、移速 6 和作业动作时长保持不变。

## 音色与试听

拾荒机以低频木质敲击、轮轴摩擦和略松散的轮组节奏为主；采集车使用更明亮的金属敲击、紧凑轮组与轻微机芯声。移动循环分别为 .8 秒和 .4 秒，与两款车的行走动画周期对应。停车时没有常驻待机声。

- [拾荒机试听](../assets/generated/audio/wood_showcase.wav)
- [采集车试听](../assets/generated/audio/metal_showcase.wav)

试听顺序为：移动循环三次、拾取、采摘、敲击、装箱、启动、暂停；采集车最后追加升级装配声。各段间隔 .35 秒。试听使用源 WAV，游戏事件另有音量衰减，最终混音需客户端验收。

| 事件末段 | 用途 | 源音频时长 |
| --- | --- | --- |
| `walk_loop` | 连续滚动声 | 木车 .8 秒，金属车 .4 秒 |
| `pickup` | 地面拾取接触 | .28 秒 |
| `pick` | 采摘与收获接触 | .35 秒 |
| `hammer` | 敲击巨大果实 | .45 秒 |
| `store` | 存放货物接触 | .32 秒 |
| `start` | 开启采集、扩展启动或再次放置 | .38 秒 |
| `stop` | 关闭采集或扩展暂停 | .28 秒 |
| `upgrade` | 套件装配，仅金属车 | .6 秒 |

完整事件路径为 `ac_collector/wood/<事件>` 与 `ac_collector/metal/<事件>`，共 15 个。音源使用 22050 Hz、16 位单声道 PCM；短声峰值约 .55，移动约 .22，首尾归零以控制接缝与叠加峰值。事件采用 3D 线性距离衰减，最小距离 2、最大距离 18；移动事件音量 -8 dB，短声 -3 dB，单事件最多同时播放 8 次。

## 原创来源与构建

`tools/build_sounds.py` 使用固定随机种子的噪声、正弦模态、摩擦滤波及衰减包络合成音源，不使用游戏、工坊或第三方音频样本。源 WAV 和 FMOD Designer 工程保留在 `assets/source/audio/`；试听在 `assets/generated/audio/`。修改音色时编辑脚本，然后重建，避免手改生成文件。

```powershell
$env:UV_CACHE_DIR = Join-Path (Get-Location) '.cache/uv'
uv run --locked -m tools.build_sounds
```

编译依赖官方 Mod Tools 的 `FMOD_Designer/fmod_designercl.exe`，安装目录不同可传 `--mod-tools "<mod_tools 路径>"`。使用旧版 Designer 的 FEV/FSB 格式，不能替换为 FMOD Studio 的 bank。生成的 `sound/ac_collector.fev` 描述事件，`.fsb` 保存 PCM；两者均由 `modmain.lua` 声明并列入发行白名单。日志和中间编译文件在 `.cache/sound_build/`，不发行。

## 接入与生命周期

`scripts/ac_sounds.lua` 按已有升级网络字段选择音色。声音由主模拟端的 prefab 与 StateGraph 调用实体 SoundEmitter，沿用引擎传播；客户端不另行重复播放作业声。

行走开始时启动命名通道 `ac_walk`，动画循环重入不会重播。进入 idle、作业或升级状态时停止；拾起、休眠和移除回调也停止并清除标记。恢复行走可重新启动。启停事件在背包和睡眠中不播放。

普通拾荒机只触发拾取、装箱和移动等运行事件；资源包保留木质采摘与敲击样本供原有素材和试听使用。采集车的 `ac_harvestenabledchanged` 复用启停提示，关闭采集时只取消采集任务，不停止正在拾取或运输的滚动声。完整 `ac_enabledchanged` 仍供扩展使用。源音频与编译包未改变，无需重新构建。

作业在原动画接触时刻重新验证目标，验证通过后只播放一次接触声并执行原动作；失效目标不播放。升级使用独立装配声，不改变升级或作业时长。

## 验证与实机验收

离线测试检查源 PCM 非静音、峰值、直流偏移、循环端点与两款区别；独立解析 FSB，逐字节核对 15 个样本。Windows 上安装有 DST 的 FMOD DLL 时，还使用 NOSOUND 输出加载事件，检查实际通道引用的 PCM 与源 WAV 完全一致、通道音量非零、短声自然结束、循环持续且可停止。此验证不启动游戏，也不通过音频设备输出。

FMOD 可能不保留样本名称；`GetName` 的空名称及编译日志中的 sound definition 去重数量不能单独判定有声或静音，必须核对实际样本数据。

用户实机验收：两款车分别移动、拾取和装箱，采集车另测采摘/收获、敲巨果及采集切换声；行走循环没有重复启动、明显接缝或停车残留。关闭采集应取消正在进行的采集任务，正在拾取或运输时滚动声继续。捡起、升级、远离休眠、移除，以及重新放置/唤醒后复查。主机、远端和晚加入客户端核对播放与停止同步；多车、镜头缩放和游戏音效音量设置下复查响度及距离衰减。0.6.2 尚未进行客户端或联网听验。
