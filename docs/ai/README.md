# AI 文档

本目录供参与本项目的 AI 使用。本项目由 AI（Codex）生成，包括代码、美术资源和动画；当前实现和可编辑源文件仍以仓库为准。

入口文件是根目录 [AGENTS.md](../../AGENTS.md)。开始任务时阅读 [协作规范](WORKFLOW.md) 和 [文档写作规范](WRITING.md)，再根据任务查看玩家或开发者文档。

| 文档 | 用途 |
| --- | --- |
| [协作规范](WORKFLOW.md) | 范围、工具、资源修改、验证与交付约束 |
| [文档写作规范](WRITING.md) | 按读者分配内容，区分当前说明、历史证据和任务交接 |
| [美术生成说明](ART_GENERATION.md) | 概念图、正式源图和历史提示词的使用边界 |
| [历次验证与交接](history/VALIDATION_HISTORY.md) | 各版本执行命令、检查结果、发行记录和用户反馈 |
| [技术诊断摘录](history/TECHNICAL_NOTES.md) | 从技术报告迁出的历史复现、修复基线与旧验证汇总 |
| [0.7.6 寻路审查记录](history/NAVIGATION_STRESS_076.md) | AI 协作过程、压力诊断、对照结果与本机缓存证据 |
| [升级套件历史实施计划](history/UPGRADE_PLAN.md) | 早期概念迭代、阶段任务和当时的交付状态 |

历史记录用于了解设计原因、复现基线和继续已有任务。旧测试数量、工作分支、缓存路径和完成状态不能替代对当前工作树的检查；某些诊断脚本只存在于记录所指的本机忽略目录中。

玩家与开发者的入口分别是 [玩家文档](../user/README.md) 和 [开发者文档](../developer/README.md)，全部维护位置见 [文档索引](../README.md)。
