# 开发者文档

本目录面向维护模组源码、制作资源或编写扩展的开发者。先阅读开发者指南，再按工作范围选择专题。

| 文档 | 内容 |
| --- | --- |
| [开发者指南](DEVELOPMENT.md) | 环境、项目结构、编码约定、构建、诊断与发行 |
| [技术报告](TECHNICAL_REPORT.md) | 当前架构、目标与容器规则、动作时序、网络及存档边界 |
| [扩展接口](API.md) | 升级、适配器、服务端组件、标签、事件和 Insight 接入 |
| [测试指南](TESTING.md) | 离线回归覆盖、本机游戏源码依赖、隔离服务器复现与验证边界 |
| [美术与动画](ART.md) | 源图、绑定、编译格式、预览与构建输出 |
| [采集车设计规格](UPGRADE_DESIGN.md) | 当前升级玩法、车身结构、套件造型和验收要求 |
| [音效](SOUNDS.md) | 原创音源、FMOD 构建、接入与声音生命周期 |
| [寻路性能约束](NAVIGATION_LIMITATIONS.md) | 已确认限制、基线证据、待改进方向与验收要求 |

玩家操作见 [README](../../README.md)，实机操作清单见 [玩家验收](../user/TESTING.md)。AI 的协作规则、生成提示词和历史交接见 [AI 文档](../ai/README.md)；它们不作为开发手册的前置阅读要求。
