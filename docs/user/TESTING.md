# 玩家手动验收

面向参与实机测试的玩家。制作、操作和配置见 [玩家说明](../../README.md)；离线回归和开发诊断见 [开发者测试指南](../developer/TESTING.md)。

在单独的测试世界中按下列项目检查。0.7.6 的后续导航与进展计时修复仍需实机验证，历史版本的结果不能替代本次检查。

## 导航修复复测

- 服务器与客户端都更新模组并重载世界。在连续转弯的窄路外侧放车，散落物品并准备样品箱；改变起点和物品位置，确认能从入口外侧进入可通行道路并送达。
- 用墙封住接收箱路径，确认箱子仍能接收时保留车内货物，状态显示运输受阻；拆墙后恢复运输，物品数量不变。箱子实际变满或过滤拒收时按玩家说明处理。
- 使用较长折返道路或让多车同时规划，观察有进展时能继续等待和移动；记录实际等待与流畅度。复杂道路仍可能触及有限搜索的上限，保货重试不代表已经找到路线。
- 在接近和交互动画期间移动目标或车身，确认取消失效交互后重新接近，不远距离收取；启用新版寻路时另在接触前添加墙体或制造水隙，确认不会隔障碍交互。
- 分别开启、关闭“启用新版寻路”并重载世界，核对 README 中各自的受阻和保货规则。另在密集障碍、多车和移动船体场景观察实际表现。

## 通用功能验收

- 开新测试世界，在炼金引擎旁确认配方、制作图标、背包图标和小地图图标。
- 将小车放入背包，确认图标完整处于单个槽位内，不覆盖边框或相邻格子。
- 放下拾荒机，检查简洁小车大小、接地位置、透明边缘及左右各两只正常轮子；确认没有夹子、盖子、货包或叠加轮子。
- 检查两款车移动到掉落物上后的车身下沉和装箱点头，以及采集车的采集/巨大作物冲撞。普通拾荒机不采摘草、树枝、农作物或敲巨果；较大物品、墙边及船上拾取路径需要实际检查。
- 检查装箱开始后约 .2 秒开启箱子，保持到约 1 秒装箱动画结束后关闭；装箱中切换采集应继续完成，捡起或让小车休眠时及时关箱。容器接触时容量不足或过滤拒收应取消装箱并寻找其他容器，无可用容器时在当前位置丢货，不出现瞬间反复开关；玩家或其他小车单纯打开箱子应保持运输，退出后保留其他开启者。内置升级保留原装箱时长，扩展动作加速才同比缩短。
- 在四个方向分别散落物品，检查移动朝向；持续按 Q/E 旋转镜头，在移动和交互动画中检查车头与屏幕上的目标方向对应。
- 散落 10 份同类物品：逐个拾取后一次卸货。再测试“已有 39 + 地面 7”的 40 上限物品，确认只取 1，其余 6 留地面；不同物品和皮肤不强行合并。
- 用采集车排列多棵成熟草、树枝等同种普通资源，确认逐株采集后统一卸货；散落同类产物时先拾取再继续采集。
- 对每株产出多个物品的普通资源，检查剩余容量不足时先卸货；填满箱子或改变过滤规则时重新验证，单纯打开箱子不取消运输，确认产物数量守恒。
- 对农作物检查每成功采摘 5 个进入拾取运输阶段，产物完整落地；无样品或满箱仍可采摘，当前无法运输的产物留地跳过。将巨大果实落点放得比下一株更远，确认仍先敲开，再继续采摘；蔬菜与额外种子分组运输。
- 小车运送途中填满目标箱子，确认有备用箱时改道；无备用箱时在当前位置丢出整组货物，空载返回中心，且不反复捡起与丢出。腾出原箱容量后应重新拾取地面货物并运输，无需暂停再启动。
- 放置多棵可敲开的巨大作物，确认先逐个完成敲击，再拾取凑组、统一送箱；不同蔬菜与种子分组处理，满组时按上限运输。
- 只留少量箱子余量，确认提前运输；确认同类目标被别的玩家拿走或路径不可达时不一直等待凑组。
- 普通拾荒机空手右键没有功能动作，拿升级套件仍能右键安装。采集车右键显示「关闭采集 / 开启采集」，关闭时停止未完成采集并继续拾取运输，已有货物和批次保留；切换时不重复交互或漏关箱。两款小车仅能鼠标左键捡起；“行动”按键默认空格或重映射后均跳过小车，仍能拾取旁边的掉落物。检查背包满时货物交还、重新放置改变工作中心并保留采集开关。
- 多台机器、玩家抢先拾取、墙后或不可达目标、箱子被打开/被敲毁、箱子过滤规则、部分堆叠余量。
- 洞穴分片、远离实体后休眠、服务器重启、船移动及船毁后的表现；旧暂停存档载入后拾取运输恢复，采集车对应关闭采集，新旧存档的采集偏好与批次正确保存。
- “仅同类箱子”和两个采集车配置；普通车始终仅拾取运输，单车右键不能开启配置禁用的采摘或敲击。
- 计划使用的第三方模组，尤其角色限定容器、自定义采摘回调和非标准成熟判定。

已完成的单元/服务器测试不能代替客户端画面、多玩家网络和所有第三方模组组合的验证。若出现问题，请保留客户端/服务器日志、模组列表、复现步骤和是否为新存档。
